# YYYYMMDD 个人周报

> 统计区间：上周五 17:00 ≤ 提交修改时间 < 本周五 17:00（Asia/Shanghai）
>
> 作者：配置中的邮箱；生成时间：实际执行时间
>
> 数据源：HEAD、本地分支及缓存远程分支；未联网同步
>
> 修改时间取 Git committer time，非文件编辑时间或上线时间

## 本周工作摘要

按成果合并提炼，不逐条翻译提交消息。没有提交时明确说明。

## 服务与模块明细

| 服务名称 | 模块 / 功能 | 实现与调整内容 | 修改时间（北京时间） | 提交依据 |
| --- | --- | --- | --- | --- |
| 实际仓库/服务 | 核实后的模块 | 说明做了什么 | 首次至末次提交时间 | 短 SHA，关联下文证据 |

## 提交依据

按服务列出完整 SHA、摘要、分支、committer time；author time 不同时补充。标记 merge、重复补丁和回退关系，使用本地仓库路径，不构造未核实的远程提交链接。

## 数据覆盖与待确认

- 配置仓库数、读取成功数、活跃仓库数、非 merge 提交数、merge 数。
- JSON 证据相对链接、浅克隆、缓存及读取失败等实际限制。
- 有证据才列待确认事项，不由 Git 推断下周计划。

## 人工补充

保留用户已有内容；首次生成可写“暂无”。
