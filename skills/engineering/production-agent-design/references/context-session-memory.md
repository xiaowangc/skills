## 1. 上下文预算

上下文工程的目标是给模型“不多不少、最相关”的信息。为每次调用分配预算：

- 行为指导：System Instructions、工具定义、少量相关示例；
- 事实证据：RAG、工具结果、子 Agent 结果和相关记忆；
- 当前任务：用户输入、必要历史、工作状态和 Artifact 引用。

记录每类上下文的来源、权威性、所有者、有效期、选择规则和最大 Token。更多上下文不等于更好；成本、延迟和 context rot 会同时上升。

## 2. Session、Memory、RAG 与 Artifact

| 类型 | 作用 | 常见范围 | 写入模式 | 主要风险 |
| --- | --- | --- | --- | --- |
| Session | 当前会话事件与工作状态 | 用户 + 会话 | 追加/状态变更 | 越权、乱序、无限增长 |
| Memory | 跨会话提取与合并的知识 | 用户/会话/应用 | 事件驱动、LLM 辅助 | 错误固化、投毒、陈旧 |
| RAG | 共享权威事实 | 应用/组织 | 离线发布 | 召回错误、版本过期 |
| Artifact | 大对象或非文本内容 | 会话/任务 | 显式创建 | 访问控制、生命周期 |

Session 是完整或近完整证据记录；发送给模型的 context 是对它的选择和变换。不要用上下文截断去破坏审计用原始事件。

Memory 不是原始聊天记录，也不是给所有用户共享的 RAG。对“工具输出”通常使用短期缓存而非长期记忆，因为它容易陈旧。

## 3. 长会话压缩

可组合使用：

- 最近 N 轮：简单但可能丢失早期承诺；
- Token 窗口：适配模型限制但不理解语义；
- 递归摘要：保留长期主题但可能产生摘要漂移；
- 任务/事件驱动压缩：在子目标结束时压缩，语义更好但需要状态识别。

摘要在后台生成并持久化，记录覆盖的 event IDs、摘要版本、模型和来源。保留最近原文与结构化关键状态，避免只依赖不断重写的摘要。

## 4. 记忆生命周期

记忆管理是主动 ETL，而非向量库别名：

1. Ingest：接收经授权的数据源；
2. Extract：按业务定义的主题提取，不是什么都记；
3. Consolidate：CREATE/UPDATE/INVALIDATE，解决重复与冲突；
4. Store：持久化内容、范围、来源、时间、置信度和版本；
5. Retrieve：按相关性、最近性、重要性和信任度检索；
6. Forget：TTL、用户删除、来源撤销、低置信或失效时删除/重建。

每条记忆保留 provenance：源类型、源 ID、时间、明示/推断、支持证据、信任级别和派生关系。冲突时优先考虑可信来源、更新信息和多源印证。

程序性记忆（如何做）和陈述性记忆（知道什么）使用不同 Schema、提取、合并和评测。程序性记忆改变行为，发布前应像 Instructions 变更一样经过回归评测和批准。

## 5. 检索与注入

检索评分至少考虑：语义相关性、时间、重要性、置信度和权限。不要只用向量相似度。

- 主动预载：适合小而稳定的用户画像；简单但每轮增加成本并可能过度影响。
- Memory-as-a-Tool：适合较大记忆集合；按需但模型可能忘记查询。
- 混合：稳定画像进入受控 System 区，情境/事件记忆按需检索。

注入记忆时标记为“可能不完整、可被新证据覆盖的背景”，避免把推断记忆伪装成用户本轮原话。保持视角一致，并限制条数与 Token。

## 6. 多智能体状态

- 共享历史：适合紧耦合流程和共同事实源；注意上下文膨胀和权限泄漏。
- 独立历史：适合黑盒专家、权限隔离和 A2A；只交换显式契约结果。
- 共享 Memory：适合跨框架共享规范化知识；不能替代事务状态或消息协议。

框架内部 Session/Event 通常不可移植。跨框架协作应共享业务 Schema、Artifact、Memory 或 A2A 消息，不直接共享私有运行时对象。

## 7. 生产与隐私

- 按用户/租户强隔离，每次访问做认证与授权；
- PII 在持久化前最小化或脱敏；
- 提供 opt-out、查看、更正、删除和来源撤销；
- 记忆生成异步化，使用幂等键、并发控制、重试和死信队列；
- 合并同一实体时使用事务或乐观锁；
- 为 Session/Memory 定义 TTL、归档和删除策略；
- 防止 Prompt 注入和恶意工具结果写入长期记忆；
- 应用级程序性记忆必须匿名化，避免跨用户泄漏。

## 8. 评测

记忆生成：Precision、Recall、F1，与人工 Golden Memories 比较。

检索：Recall@K、授权正确率、陈旧信息率和延迟预算。

端到端：有/无记忆的任务成功、个性化收益、错误记忆造成的伤害和成本差异。

专门加入：偏好变化、冲突来源、删除请求、跨租户攻击、投毒、过时信息、多语言和长会话摘要漂移样本。
